Frequently Asked Questions

Everything you need to know.

Is Doing It free and open source?
Yes, 100%. Doing It is licensed under the permissive MIT License. You can audit every line of code, run it completely offline, or contribute on GitHub.
Why does Windows Defender SmartScreen show an alert?
Commercial Windows code-signing certificates cost hundreds of dollars per year. As an independent open-source project, Doing It is distributed directly without a corporate certificate. When installing, simply click "More info" and select "Run anyway". Doing It never sends data to any server.
Where is my data stored? Can I sync across devices?
Your data is stored strictly locally in standard JSON files inside your %APPDATA% directory. You can also use the Bring Your Own Cloud (BYOC) feature in Settings to redirect your storage path to OneDrive, Google Drive, or Dropbox for instant, private cross-device sync.
Does Doing It require an internet connection?
No. Doing It is architected local-first. All task management, markdown parsing, ambient sound synthesis, and keyboard capture work completely offline without an active network connection. An internet connection is only used if you configure remote .ics calendar sync or embed Spotify playlists.
How do backups and data export work?
Doing It automatically creates rolling daily snapshots in a local backups/ folder on startup. In addition, you can export your entire database to a clean JSON file at any time from Settings or via the Command Palette (Ctrl+K → Data: Export Backup JSON).
