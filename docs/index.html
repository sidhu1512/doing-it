Architecture Principles

Local-first. 100% Private. Always yours.

Your private thoughts, daily reflections, voice memos, and task lists should never be held hostage by a cloud subscription.

Atomic Local JSON Storage

All state is staged atomically in standard human-readable JSON files on your local drive with automatic 5-day rolling backups. Zero database corruption risk.

Zero Accounts & Zero Tracking

No sign-up forms. No password resets. No Google analytics, telemetry SDKs, or background pings. Doing It works completely offline on an airplane.

Zero Input Latency (<1ms)

Because operations execute directly in memory with reactive DOM observers, adding tasks or editing notes has no network latency.

Permissive MIT Open Source

Auditable, inspectable, and freely forkable. You own your software and your workflow forever without fear of sudden sunsetting or price increases.

Questions & Answers

Frequently asked questions.

Everything you need to know about installation, privacy, and operating system support.

What versions of Windows are supported? ↓

Doing It is built and verified for 64-bit Windows 11 and Windows 10 (version 1809 and later). It supports native Mica acrylic materials on Windows 11 while gracefully falling back to optimized dark/light surfaces on Windows 10.

How does Doing It sync with my calendar? ↓

Doing It syncs via RFC 5545 private iCalendar feeds (.ics URLs) provided by Google Calendar, Microsoft Outlook, Fastmail, or Apple iCloud. Your machine fetches and parses the feed directly without transmitting credentials to any intermediary proxy server.

Where is my data stored on my PC? ↓

All tasks, diary entries, voice notes, and habit records are stored in your Windows user profile at %APPDATA%/doing-it/doing-it-data.json. You can also select a custom storage directory (e.g. OneDrive, Dropbox, or Syncthing) inside Settings to sync across your own personal devices.

Does the ambient focus audio use network bandwidth? ↓

No. The ambient sound synthesizer (Brown Noise, Rainfall, Forest Wind, and 6Hz Binaural Beats) is 100% procedurally synthesized in real time via the Web Audio API with zero audio file downloads and zero bandwidth consumption.

Is Doing It free to use commercially? ↓

Yes. Doing It is licensed under the permissive MIT Open Source License. You are free to use it for personal, commercial, or organizational work without fees or subscription locks.
