FAQ

Frequently asked questions.

Is Doing It free and open source?
Yes, 100%. Doing It is released under the permissive MIT License. You can audit every line of code, run it completely offline, or contribute on GitHub. Zero paywalls, zero subscriptions, zero artificial limits.
Where is my data stored? Can I sync between PCs?
All data is stored locally in standard JSON files inside your %APPDATA%/doing-it folder with atomic rename staging. You can also use the Bring Your Own Cloud (BYOC) setting to redirect your data directory to OneDrive, Google Drive, or Dropbox for instant, private cross-device sync.
Does Doing It require an internet connection?
No. Doing It is local-first. Task management, Day One journaling, voice recording, markdown parsing, ambient sound synthesis, and keyboard capture work completely offline. Network connectivity is only used if you configure remote .ics calendar sync.
How does backup export and restore work?
Doing It creates rolling daily snapshots in a local backups/ folder on startup. In addition, you can export your entire database to a clean JSON file at any time from Settings or via Command Palette (Ctrl+K → Data: Export Backup JSON).
How does Spotify desktop control work?
Doing It inspects the local Windows Spotify desktop client process window title with zero network overhead. It extracts the currently playing artist and song title in real time, and sends native Windows media key commands for instant Prev, Play-Pause, and Next.
